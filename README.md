# SmartCalc Android

Features:
- Standard arithmetic keypad and business percentage calculations.
- Configurable positive and negative GST quick-rate buttons (four each).
- Settings persist after closing/reopening the app.
- Restore default GST rates and settings.
- Decimal precision from 0 to 6 places.
- Light and dark themes.

## Build
Open this repository in GitHub and run **Actions → Build SmartCalc APK → Run workflow**.
Download the `SmartCalc-APK` artifact from the successful run. It contains `app-debug.apk`.
